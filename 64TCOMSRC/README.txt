64TCOMSRC — 64TCOM director / compiler sources
==============================================
Adapted from classic TCOM core concepts (COMPILE1, COMPILE2, HEAD2, HOST,
TCOMNDX, …) for native 64Forth (8-byte cells). Not an F-PC translation layer.

Files will land here as Phase 1 proceeds (e.g. host-support, head2, compile1,
compile2, host, …). Names may be modernized (.fth) while preserving roles.

TARGETGEN.txt — 64TCOM GEN (generic) target
============================================
Product:  64TCOM
Pack:     GEN
Host:     64Forth (native 64-bit cells)
Status:   Phase 2 scaffold — loadable stubs (2026-08-05)

Purpose
-------
GEN does not generate code for a real microprocessor. It exercises the
64TCOM host layer and a thin director: symbols/cookies, deferred hooks,
target image buffers, and a readable compile log.

Load
----
  On 64Forth, CHDIR to 64TCOMGEN (or INCLUDE this pack by full path):

    FLOAD TARGETGEN.fth

  That loads:

    ../64TCOMSRC/64HOST.fth
    ASMGEN.fth
    OPTGEN.fth
    LIBGEN.fth

  Then try:

    .GEN
    GEN-DEMO
    FLOAD TESTGEN.fth

GEN tag stream (in T-CODE-BASE image)
-------------------------------------
  $01  LIT     + T-CELL
  $02  CALL    + T-CELL
  $03  RET
  $04  NOP
  $05  JMP     + T-CELL
  $06  0BRANCH + T-CELL
  $10  HEADER  + length + name bytes

Thin director words (OPTGEN)
----------------------------
  TARGET-INIT   clear/allocate image, set order
  T: name … ;T  target definition (host word returns cookie)
  L: name … ;L  library-style definition
  G,            compile literal tag
  GCALL / GJMP  compile call/jump tag
  LIB,          ' DUP# LIB,  — call library cookie
  GEN-FINISH    cleanup / optional “save” message
  GEN-DEMO      built-in smoke test

Library cookies (LIBGEN) use safe names ending in # :
  DUP# DROP# NOOP# LIT# EXIT# …

Not yet
